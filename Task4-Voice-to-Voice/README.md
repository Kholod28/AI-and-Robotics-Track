# Voice-to-Voice AI Assistant

## Description
This project is a Voice-to-Voice AI Assistant built with Python. It converts speech into text, sends it to the Gemini AI model, and converts the response back into speech.

## Features
- Speech-to-Text
- Gemini AI Response
- Text-to-Speech

## Technologies Used
- Python
- SpeechRecognition
- Google Gemini API
- gTTS
- PyAudio

## How to Run

1. Install the required libraries:
pip install -r requirements.txt

2. Add your Gemini API Key in main.py.

3. Run:
python main.py
