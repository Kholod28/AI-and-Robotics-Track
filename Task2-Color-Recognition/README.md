# Color Recognition using OpenCV

## Project Description

This project detects multiple colors in real time using a webcam and OpenCV.

The program recognizes the following colors:
- Red
- Blue
- Green
- Yellow
- White
- Black

For each detected object, the program:
- Draws a bounding box.
- Displays the color name.
- Counts the number of detected objects for each color.

## Requirements

- Python 3.x
- OpenCV
- NumPy

Install the required libraries:
pip install opencv-python numpy

## Run
python color_recognition.py

## Output

The webcam opens and detects colored objects in real time while displaying their names and counts.
